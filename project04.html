사내 그룹웨어
HR 관리 플랫폼

사내 업무 및 인사 관리 프로세스를 통합하고,
조직 구조와 사용자 권한 기반으로 효율적인 업무 흐름과
협업 환경을 설계한 그룹웨어 플랫폼

Device PC (1440px ~ 1920px)
Timeline 25.12 - 26.04 (5개월)
Role UX Planning &
UI Design (100%)
Core Goal 사내 인사 및
업무 프로세스 통합
디자인 전략 및 핵심 목표

사내 운영 데이터를 조직 체계 중심으로 통합

인사, 근태, 전자결재, 권한 관리 등 분산된 사내 업무 기능을 하나의 흐름으로 연결하고, 조직 구조와 사용자 역할에 맞춘 정보 체계를 구축해 실제 업무 효율과 협업 생산성을 높일 수 있게 설계했습니다.

조직 구조 기반 권한 관리 설계

조직도, 부서, 직책, 역할 권한을 기준으로 사용자 접근 범위를 구조화하고, 업무 특성에 따라 필요한 메뉴와 데이터를 효율적으로 연결할 수 있도록 설계

Why This Way? 그룹웨어는 사용자마다 사용하는 기능과 접근 정보가 크게 다르기 때문에, 일관된 화면 제공보다 역할 기반 정보 구조를 통해 업무 집중도와 운영 효율을 높이는 것이 중요했음

업무 흐름 중심 전자결재 UX 설계

기안 작성부터 승인·반려·이력 관리까지 이어지는 결재 프로세스를 단계별 흐름 중심으로 설계하고, 상태 변화와 진행 상황을 직관적으로 확인할 수 있도록 구성

Why This Way? 전자결재는 단순 문서 작성보다 현재 상태와 처리 흐름 파악이 핵심이기 때문에, 복잡한 결재 구조를 빠르게 이해하고 처리할 수 있는 업무 중심 UX가 필요했음
사용자 주요 UI 화면 설계

일상 업무 흐름을 단순화한 직관적 UX 구조

인사, 근태, 결재 등 반복적인 업무를 최소한의 단계로 처리할 수 있도록 정보 구조를 재정렬하고, 사용자의 업무 흐름 중심으로 화면을 설계했습니다.

관리자 주요 UI 화면 설계

조직 운영과 권한 관리를 통합한 운영 중심 UX 구조

조직, 사용자, 권한, 업무 데이터를 통합적으로 관리할 수 있도록 운영 관점에서 정보를 구조화하고, 복잡한 설정과 관리 업무를 효율적으로 처리할 수 있도록 설계했습니다.

탭을 눌러 화면을 전환해보세요
UI/UX 설계 정책

개발 협업을 위한 인터랙션 및 컴포넌트 동작 기준 정의

모달 위치, 스크롤 동작, 토스트 알림 등 UI 컴포넌트의 동작 방식을 일관된 규칙으로 정의하고, 해석 차이를 줄여 구현 정확도와 협업 효율을 높이기 위해 설계했습니다.

인터랙션 컴포넌트 동작 기준 정의

모달 위치, 토스트 알림 위치, 드롭다운 동작 방식 등 UI 컴포넌트의 동작 규칙을 일관되게 정의하여 개발 및 디자인 간 해석 차이를 줄이고 구현 기준을 확립

화면 전환 및 상태 구조 정의

페이지 이동, 스크롤 영역, 모달 진입/종료 등 화면 상태 변화 흐름을 기준으로 UX 구조를 정리하여 사용자 경험의 일관성과 흐름 중심 설계를 확립

디자인 시스템 제작

일관된 사용자 경험을 위한 디자인 시스템 설계

분산된 UI 요소를 통합하고, 컴포넌트 기반 설계를 통해 일관성과 확장성을 확보했습니다.

UI 일관성 확보

컬러, 타이포그래피 등 기준을 표준화하여 화면 간 시각적 불균형을 제거하고 사용자 경험의 일관성 유지

컴포넌트 기반 설계

재사용 가능한 컴포넌트 구조를 정의하여 디자인 및 개발 생산성을 향상시키고 유지보수 비용 절감
