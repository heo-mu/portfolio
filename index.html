About

사용자가 다음 행동을
알 수 있는 구조를 설계해요.

  1. Agency

    에이전시에서 시작했어요. 17개 웹사이트를 구축하며 다양한 요구사항을 화면 구조와 서비스 흐름으로 정리했어요.

  2. In-house · B2B SaaS

    인하우스 B2B SaaS에서는 UX 기획까지 맡았어요. 정보 구조와 화면 정책을 설계하고, 프론트엔드 엔지니어와 컴포넌트·상태·반응형 기준을 디자인 시스템으로 만들었어요.

  3. SI · Solution 현재

    지금은 SI 솔루션 업체에서 일해요. 여러 프로젝트의 복잡한 데이터와 업무 조건을 사용자가 이해하기 쉬운 정보와 행동 순서로 바꾸고 있어요.

AI는 제작과 검토 시간을 줄이는 데 활용해요. 이미지·아이콘 제작과 반복 작업에 적용하고, HTML 그래프를 Figma로 옮기는 플러그인도 만들어 화면과 흐름을 검토할 시간을 확보했어요.

AI in my workflow

판단은 직접,
반복은 AI로 줄여요.

요구사항을 정리하고, 화면을 비교하고, QA 범위를 넓혀요. 반복해서 손이 가는 작업은 AI로 줄이고, 그만큼 제품의 구조와 사용자 흐름을 더 많이 봐요.

01

요구사항을 설계 단위로 나눠요.

긴 기획 내용도 기능·사용자·상태·예외 조건으로 먼저 나눠요. 화면을 그리기 전에 무엇부터 풀어야 하는지 빠르게 정리해요.

02

비슷한 화면의 차이를 먼저 찾아요.

화면이 많을수록 정책·권한·상태 차이를 AI로 먼저 비교해요. 중복 작업은 줄이고, 실제로 달라져야 하는 부분에 집중해요.

03

반복 제작은 작업 방식부터 바꿔요.

그래프처럼 손이 많이 가는 작업은 HTML로 빠르게 만들고, AI로 만든 Figma 플러그인을 통해 바로 활용하는 방식도 만들어봤어요.

04

놓치기 쉬운 상태를 더 많이 확인해요.

반응형·빈 화면·오류·권한·텍스트 잘림 같은 항목을 AI로 먼저 정리해요. 마지막 판단은 실제 화면을 보면서 직접 확인해요.

05

필요한 비주얼은 더 빠르게 만들어요.

이미지와 아이콘처럼 작업 중 필요한 비주얼은 AI로 빠르게 만들어요. 그대로 쓰지 않고 제품의 톤과 화면에 맞게 다시 다듬어 활용해요.
