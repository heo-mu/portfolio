화면부터 그리지 않아요. 데이터와 기능의 관계, 사용자가 막히는 지점을 먼저 살펴봐요.

반복적인 정리와 탐색에는 AI를 활용해요. 여러 가능성을 빠르게 비교하고, 그만큼 디자인 판단에 더 집중해요.

더 많이 비교하고 검토할 수 있도록 AI를 활용해요. 기준을 정하고 최종안을 고르는 일은 직접 해요.

01

복잡한 내용을 빠르게 정리해요.

요구사항과 데이터를 AI로 먼저 분류해요. 빠진 맥락을 살펴보고, 제품에서 중요한 관계와 우선순위는 직접 정해요.

↗
02

여러 방향을 비교해요.

흐름과 화면의 여러 가능성을 빠르게 펼쳐봐요. 사용자에게 맞는 방향을 고르고, 선택한 이유를 분명하게 남겨요.

⌘
03

반복 작업을 줄여요.

반복되는 정리와 초안 작업을 작은 단위로 나눠 AI에 맡겨요. 결과를 확인하면서 설계 판단에 더 집중해요.

⊞
04

놓친 상태를 다시 확인해요.

화면과 정책을 함께 검토하며 누락된 상태와 예외를 찾아요. 실제 사용 흐름에 맞는지 직접 확인하고 다듬어요.

▷
05

디자인 판단은 직접 해요.

AI의 결과를 그대로 쓰지 않아요. 사용자와 제품의 기준에 맞춰 채택하거나 수정하고, 필요 없는 제안은 덜어내요.
