01 / OVERVIEW

프로젝트 개요

분산된 ESG 데이터를 한곳에 모아, 관리자와 사용자 권한에 따라 필요한 정보를 연결하는 ESG 통합 관리 플랫폼

ESG Management / Web / B2B SaaS / AI Analysis / UI/UX / RBAC

02 / 디자인 전략 및 핵심 목표

분산된 ESG 데이터를 공시와 실행까지 연결하는 운영 중심 설계

ESG 데이터를 공시, 목표 설정, 성과 관리, AI 분석까지 한 흐름으로 묶어 실제 업무에 바로 쓰게 만들었어요.

ESG 목표 기반 성과 관리

기업의 ESG 지표를 실행할 목표로 바꾸고, 단기·중간·최종 단계로 나눠 설정부터 달성까지 이어지게 했어요

설계 판단 ESG 데이터는 관리보다 실행이 중요해서, 지표를 목표 단위로 다시 묶어야 해요

공시·AI 분석 통합 정보 구조 설계

ESG 데이터 입력, 공시, AI 분석 결과를 한 흐름으로 연결해 별도 해석 없이도 이해하고 활용하게 만들어요

설계 판단 ESG 플랫폼은 데이터 → 공시 → 분석 → 활용이 한 흐름으로 이어져야 해요
03 / ESG 목표 관리

‘목표’ 서비스 기획 및 디자인

ESG 인벤토리 데이터를 바탕으로 단기·중간·최종 목표를 세우고 달성 현황을 확인하는 메뉴예요.

메뉴 목적 요약

한 기업의 ESG 지표를 ‘관리 가능한 목표’로 바꿔 실행 현황을 관리해요

인벤토리의 정량 지표를 바탕으로 단기·중간·최종 목표를 설정해요

목표와 실적을 비교해 변화 추이와 달성 현황을 확인해요

목표 분류 진행 단계 UI 설계 및 시각화

단기/중간/최종 목표를 단계별로 나누고, 수립부터 달성까지 상태를 한눈에 보게 구성해요

사용자 경험 개선을 위한 필터링 및 인터랙션 고도화

달성 여부와 담당자 같은 필터를 더해 원하는 항목을 빨리 찾게 하고 목록도 단순하게 정리해요

예외 케이스 대응을 고려한 UX 설계

UI 오류 대응 방식을 정하고 다양한 상황에 맞는 화면을 만들어요

04 / AI 보고서 검토

‘AI 보고서 GUIDA’ 서비스 디자인

작성한 보고서를 AI로 검토하고, 확인할 내용을 항목별로 나눠 보여주는 메뉴예요.

메뉴 목적 요약

사용자가 작성한 보고서를 AI가 검토하고, 확인할 항목을 나눠 보여줘요

항목별 리뷰 결과를 보기 쉽게 정리해 보여줘요

정해진 프롬프트 구조에 따라 일관된 분석 결과를 출력

직관적인 탭 기반 UI

항목별 보고서를 작성하고 필요한 시점에 AI 검토를 실행하게 했어요

리뷰 결과 가독성을 고려한 UI 설계

AI 검토 결과를 항목별로 나누고, 먼저 확인할 내용이 드러나도록 우선순위를 정했어요

개발을 위한 디스크립션 작성

화면과 기능 흐름을 자세히 적어 개발자가 같은 기준으로 구현하게 해요

05 / UI/UX 설계 정책

일관된 사용자 경험을 위해 UI/UX 설계 기준 수립

기획과 디자인에 쓰는 이름, 문장, 인터랙션 기준을 정해 화면마다 같은 원칙을 적용했어요.

사용자 경험 구조 정의

기능 간 관계와 이동 경로를 정리해 복잡한 서비스를 흐름 중심으로 이해하고 설계할 수 있게 해요

일관된 인터페이스 기준 설계

사용자 행동에 따른 상태 변화와 반응을 정리해, 서비스 전체에서 같은 방식으로 작동하게 했어요

06 / 디자인 시스템 제작

일관된 사용자 경험을 위한 디자인 시스템 설계

화면마다 달랐던 UI 기준을 하나로 묶고, 반복해서 쓸 수 있는 컴포넌트로 정리했어요.

UI 일관성 확보

컬러, 타이포그래피 등 기준을 표준화하여 화면 간 시각적 불균형을 제거하고 사용자 경험의 일관성 유지

컴포넌트 기반 설계

재사용할 수 있는 컴포넌트 구조를 정해 디자인과 개발의 반복 작업을 줄여요.

07 / Figma 협업 프로세스

디자인 협업 프로세스와 구조화 전략

주석 기반 설계 문서 정의

Figma 주석을 UI 요소에 바로 연결해 기능, 동작, 예외 상태를 화면 안에서 확인하게 했어요

디자인-개발 간 커뮤니케이션 방식 개선

주석에 기능, 상태, 예외 흐름을 함께 적어 화면만으로 구현 기준을 확인하게 했어요

08 / 주요 UI 화면 설계

복잡한 ESG 데이터를 직관적인 정보 구조로

분산된 ESG 데이터를 한곳에 모아 핵심 지표를 빠르게 파악할 수 있게 정리했어요.
