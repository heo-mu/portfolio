01 / OVERVIEW

프로젝트 개요

복잡한 에너지 데이터를 통합·구조화하고, 사용자 맥락에 맞는 정보 체계를 설계한 건물관리시스템

Digital Twin / Unreal Engine / Building Energy / UI/UX

02 / 디자인 전략 및 핵심 목표

단순 정보 나열을 넘어선 흐름 중심 설계

복잡한 에너지 데이터를 나열하지 않고, 사용자가 확인하고 판단한 뒤 행동으로 이어지게 구성했어요.

계층형 탐색 구조

건물 → 층 → 설비 순서로 이동하며, 복잡한 데이터를 기능이 아닌 공간 단위로 찾게 했어요

설계 판단 기능 이름을 익히지 않아도 실제 공간을 따라 원하는 설비로 이동할 수 있어요

맥락 유지 인터페이스 설계

상태를 확인한 화면에서 필요한 조치까지 바로 이어지도록 인터페이스를 설계했어요

설계 판단 화면 전환이 많아질수록 흐름이 끊기기 때문에, 한 화면 안에서 확인 → 판단 → 실행이 이어지도록 설계
03 / 디자인 시스템 제작

일관된 사용자 경험을 위한 디자인 시스템 설계

화면마다 달랐던 UI 기준을 하나로 묶고, 반복해서 쓸 수 있는 컴포넌트로 정리했어요.

System 구축 전략

UI 일관성 확보

컬러, 타이포그래피 등 기준을 표준화하여 화면 간 시각적 불균형을 제거하고 사용자 경험의 일관성을 유지

컴포넌트 기반 설계

재사용할 수 있는 컴포넌트 구조를 정해 디자인과 개발의 반복 작업을 줄여요.

04 / 실시간 운영 대응 에이전트

AI 기반 통합 관제 에이전트

현장의 설비 상태와 이상 신호를 대화형 인터페이스로 묶어, 별도 화면을 찾지 않아도 바로 상황을 파악하고 대응하게 했어요. 실시간 데이터에서 위험 징후를 먼저 찾아 필요한 조치와 경로를 보여줘요.

한눈에 파악되는 상태 정보

실시간 알림과 대화형 인터페이스를 결합해, 복잡한 수치를 해석하지 않아도 현재 상황을 바로 이해하게 만들어요

바로 실행할 수 있는 인터페이스

알림 확인에서 끝나지 않고, 필요한 행동까지 한 흐름으로 이어서 다음 행동을 고민하지 않게 만들어요

05 / Figma 협업 프로세스

디자인 협업 프로세스와 구조화 전략

Slot 신기능 활용

슬롯 기반 재사용 중심 구조 설계

슬롯(Slot)으로 여러 UI를 하나의 패턴 안에서 조합하게 했어요. 같은 구조를 반복해서 만들지 않아도 돼요

주석 기능 활용

해석 비용 없는 의도 전달

주석에 UI 상태, 인터랙션, 예외 케이스를 함께 적어 구현 기준을 화면에서 바로 확인하게 했어요

06 / 주요 UI 화면 설계

복잡한 에너지 데이터를 직관적인 정보 구조로

분산된 에너지 데이터를 통합·구조화해 핵심 지표를 빠르게 파악할 수 있는 정보 체계를 만들었어요.
