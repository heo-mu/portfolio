01 / OVERVIEW

프로젝트 개요

제품 규격과 실제 공간을 3D로 비교해 구매 전 설치 가능 여부를 확인하고, AI로 반복 확인과 수정 시간을 줄인 서비스

3D Fit Checker / AI Workflow / Responsive Web / UI/UX

현재 제품 구조와 사용자 흐름을 설계하고 있어요. 조건을 정리하고 여러 상태를 비교하며 다듬은 과정을 담았어요.

02 / 디자인 전략 및 핵심 목표

구매 전에 설치 가능 여부를 확인하는 구조 설계

냉장고는 규격을 알아도 실제로 설치할 수 있을지 판단하기 어려워요. 제품과 공간을 함께 확인할 기준이 필요했어요.

규격만으로 어려운 판단

상세 페이지의 치수만으로는 실제 주방에 들어갈지 가늠하기 어려움

문 열림과 주변 공간

본체가 들어가도 문을 여는 공간과 벽 · 주변 여유가 없으면 사용 불가

구매 이후에 드러나는 문제

배송 당일에 확인하면 반품과 재설치 비용이 발생

들임은 제품과 실제 공간을 3D에서 함께 확인하게 해 구매 전에 설치 가능 여부를 판단하도록 설계한 서비스
03 / 핵심 사용자 흐름

제품 선택에서 설치 결과까지 3단계 구성

STEP 1

제품 선택

검토할 냉장고를 선택해 이후 설치 판단에 사용할 제품 규격을 정해요.

STEP 2

공간 설정 및 3D 조정

설치 공간의 치수를 입력하고 선택한 제품을 3D에서 직접 배치해요.

STEP 3

설치 결과 확인

설치 가능 여부와 남는 공간, 확인할 조건을 결과 화면에서 봐요.

04 / UI/UX 설계 정책

흐름 · 단위 · 용어의 설계 기준 수립

설치 가능 여부는 제품과 공간을 함께 봐야 판단할 수 있어요. 화면을 만들기 전에 세 가지 기준을 먼저 정했어요.

01. 사용자 흐름 — 맥락을 가리지 않는 단계 구성

BEFORE
제품 선택 → Modal → 공간 입력 → 3D
AFTER
제품 선택 → 공간 설정 → 3D Fit Checker

모달이 직전에 선택한 제품을 가리는 구조를 제거하고, 단계를 연결해 작업 맥락 유지

02. 데이터 계약 — 표시 단위와 계산 단위 분리

사용자에게 표시 cm — 사용자가 공간을 가늠할 때 실제로 쓰는 단위
내부 판정 · 계산 mm — 반올림으로 판정이 뒤집히지 않도록 더 작은 단위로 계산

계산 정확성과 읽기 편한 표기를 함께 지키기 위해 두 단위별 역할을 나눠요

03. 용어 체계 — 역할에 따른 문법 구분

행동 (Action) 결과 보기 — 사용자가 수행하는 동작이므로 동사형
도착 화면 (Heading) 설치 결과 — 도착한 화면의 이름이므로 명사형
제품 재선택 제품 변경 — 대상이 분명한 조작이므로 대상과 동작을 함께

모든 문구를 한 형식으로 통일하지 않고, 화면에서 맡은 역할에 따라 문법을 구분

05 / AI 활용 제작 과정

디자인 기준을 정하고 빠르게 비교하는 작업 흐름

UX 기준과 완료 조건은 직접 정하고, AI로 반복 작업을 줄이며 여러 상태를 빠르게 확인했어요.

01 Define

해결할 문제와 사용자 흐름, 바꿀 범위와 유지할 범위를 정해요.

02 Design

UX 정책과 화면 기준, 무엇을 충족해야 완료인지의 조건을 정해요

03 Explore

반복해서 확인할 내용을 작은 작업 단위로 나눠요.

04 Review

화면과 상태의 차이를 비교하고, 발견한 문제는 원인을 찾아 수정해요.

작업 지시 구조

Context → Goal → Constraints → Acceptance Criteria → Validation
06 / 검증 및 개선

증상 대신 원인을 수정하는 검증 구조

화면만 임시로 고치지 않고, 데이터와 제품 기준에서 원인을 찾아 수정했어요.

문제 특정 너비에서 치수 단위가 잘못 출력됨
판단 화면별 수정으로는 재발한다고 보고, 단위의 책임을 제품 기준으로 분리
해결 표시용 cm 와 계산용 mm 의 경계를 정의해 계산값이 화면으로 새지 않게 함
문제 여유 공간이 음수일 때 계산값이 그대로 노출됨
판단 음수는 계산에는 의미가 있어도 사용자에게는 읽히지 않는 값이라 판단
해결 계산 데이터와 사용자 문구의 역할을 분리하고, 설치 불가를 상태 표현으로 전환
문제 좁은 화면에서 한글 줄바꿈이 어색하고 단어가 잘리는 현상
판단 최소 너비를 예외가 아니라 상시 검수 기준값으로 고정
해결 390px 와 320px 을 기준 너비로 두고 의미 단위로 끊기도록 처리 기준 정의

화면 너비와 상태 전환을 바꿔 가며 데이터·인터랙션·런타임 오류를 반복해서 확인해요.

07 / 진행 현황과 배운 점

복잡한 설치 조건을 이해하기 쉬운 흐름으로

공간·제품·설치 조건의 관계를 먼저 정리하고 여러 상태를 반복해서 비교했어요. 사용자가 숫자와 3D 결과를 함께 이해하는지 확인했고, 디자인 판단과 품질 기준은 끝까지 직접 정하고 검수했어요.
