3D Fit Checker

들임구매 전에 설치 가능 여부를 확인하는 3D 서비스

냉장고 치수와 실제 설치 공간을 3D에서 함께 비교하는 서비스예요. 흩어진 수치 대신 ‘이 공간에 설치할 수 있는가’라는 판단을 중심으로 흐름과 상태, 단위와 문구의 기준을 설계했어요.

01Context

치수만으로는 판단하기 어려운 설치 조건

냉장고는 규격을 알아도 실제로 들어갈지 판단하기 어려워요. 문제가 배송 당일에 드러나면 반품과 재설치로 이어져요.

규격만으로 어려운 판단

상세 페이지의 치수만으로는 실제 주방에 들어갈지 가늠하기 어려워요.

문 열림과 주변 공간

본체가 들어가도 문을 열 공간과 벽 주변 여유가 없으면 쓸 수 없어요.

구매 이후에 드러나는 문제

배송 당일에 확인하면 반품과 재설치 비용이 생겨요.

설계 관점

각 수치보다 ‘이 공간에 설치할 수 있는가’라는 최종 판단이 중요하다고 봤어요. 그래서 기능을 더하기 전에 제품 선택 → 공간 설정 → 설치 결과의 순서부터 정했어요.

02User Flow

제품 선택부터 설치 결과까지 3단계 흐름

선택한 제품의 규격을 기준으로 공간을 설정하고, 결과를 확인하는 순서로 나눴어요.

  1. 01

    제품 선택

    설치 판단에 쓸 냉장고와 규격을 정해요.

  2. 02

    공간 설정과 3D 조정

    설치 공간의 치수를 입력하고 제품을 3D에서 직접 배치해요.

  3. 03

    설치 결과 확인

    설치 가능 여부와 남는 공간, 추가로 확인할 조건을 봐요.

단계 연결 방식

Before

  1. 제품 선택
  2. 모달
  3. 공간 입력
  4. 3D

After

  1. 제품 선택
  2. 공간 설정
  3. 3D Fit Checker

직전에 고른 제품을 모달이 가리던 구조를 없애고, 선택한 제품을 보면서 공간을 설정하도록 단계를 이었어요.

03Design Decisions

단위⁠·⁠상태⁠·⁠문구의 설계 기준

설치 판정이 흔들리지 않도록 계산과 표시, 상태와 문구의 역할을 먼저 나눴어요.

01

표시 단위와 계산 단위 분리

문제
특정 화면 너비에서 치수 단위가 잘못 출력됐어요.
판단
화면마다 고치면 다시 생긴다고 보고, 단위의 책임을 제품 기준으로 나눴어요.
설계
화면에는 cm, 판정과 계산에는 mm를 쓰도록 경계를 정해 반올림으로 판정이 뒤집히지 않게 했어요.

02

계산값 대신 설치 상태

문제
여유 공간이 음수일 때 계산값이 그대로 보였어요.
판단
음수는 계산에는 의미가 있어도 사용자에게는 읽히지 않는 값이라고 봤어요.
설계
계산 데이터와 사용자 문구를 분리하고, ‘설치 불가’ 상태와 확인할 조건으로 보여줬어요.

03

역할에 따라 나눈 문구 문법

문제
모든 문구를 한 형식으로 맞추면 누르는 행동과 도착한 화면이 구분되지 않아요.
판단
문구가 화면에서 맡은 역할에 따라 문법을 달리해야 한다고 봤어요.
설계
행동은 ‘결과 보기’처럼 동사형, 도착 화면은 ‘설치 결과’처럼 명사형으로 쓰고, ‘제품 재선택’은 대상이 분명한 ‘제품 변경’으로 바꿨어요.

04

좁은 화면을 기본 조건으로

문제
좁은 화면에서 한글 줄바꿈이 어색하고 단어가 잘렸어요.
판단
최소 너비를 예외가 아니라 상시 검수할 기준으로 봤어요.
설계
390px와 320px를 기준 너비로 두고, 문장이 의미 단위로 끊기도록 처리 기준을 정했어요.

04AI Workflow

반복 확인을 줄이는 AI 작업 구조

UX 기준과 완료 조건은 직접 정하고, 여러 화면과 상태를 반복해서 확인하는 일을 AI로 줄였어요.

  1. 01

    Define

    해결할 문제와 사용자 흐름, 바꿀 범위와 유지할 범위를 정해요.

  2. 02

    Design

    UX 정책과 화면 기준, 무엇을 충족해야 완료인지 조건을 정해요.

  3. 03

    Explore

    반복해서 확인할 내용을 작은 작업 단위로 나눠요.

  4. 04

    Review

    화면과 상태의 차이를 비교하고, 발견한 문제는 원인을 찾아 고쳐요.

작업 지시 구조

AI에 작업을 맡길 때는 이 순서로 조건을 정리했어요.

지시 순서

  1. Context
  2. Goal
  3. Constraints
  4. Acceptance Criteria
  5. Validation

AI

AI에 맡긴 일

  • 반복해서 확인할 내용을 작은 작업 단위로 나눠 처리했어요.
  • 여러 화면과 상태의 차이를 비교했어요.

Designer

직접 판단한 일

  • 해결할 문제와 바꿀 범위⁠·⁠유지할 범위를 정했어요.
  • UX 정책과 완료 조건을 세웠어요.
  • 결과가 기준에 맞는지 직접 검수했어요.

05Result

설치 판단을 돕는 흐름과 검수 기준

진행 중인 프로젝트로, 지금까지 정리한 흐름과 기준이에요.

  1. 01

    선택 맥락을 잇는 3단계 흐름

    모달 없이 제품 선택 → 공간 설정 → 설치 결과로 이어져요.

  2. 02

    판정이 흔들리지 않는 단위 기준

    표시 cm와 계산 mm의 경계를 정해 계산값이 화면에 그대로 나오지 않아요.

  3. 03

    상시 검수하는 좁은 화면

    320px⁠·⁠390px에서 문장과 상태 전환을 함께 확인해요.

이 프로젝트에서 보여준 역량

  • 복잡한 조건의 구조화제품⁠·⁠공간⁠·⁠설치 조건의 관계를 단계로 정리했어요.
  • 상태와 문구 설계계산 결과를 사용자가 이해할 상태와 행동으로 바꿨어요.
  • AI 작업 기준 설계AI에 맡길 반복 작업과 직접 판단할 기준을 나눴어요.

다음 작업에 가져갈 기준

제품 규격과 공간의 관계를 먼저 정리해야 숫자와 3D 장면이 같은 판단을 도와요. 반복 확인은 AI에 맡기더라도 완료 조건과 품질 기준은 직접 정한다는 원칙을 다음 작업에도 이어가요.
