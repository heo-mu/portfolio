고용노동부 AX사업장 AI 자율점검 시스템

근로계약서와 현장 사진을 AI가 분석하는 공공 서비스예요. 분석 결과를 그대로 믿게 하지 않고, 사용자가 원문과 비교해 직접 확인한 뒤 점검과 조치로 넘어가도록 흐름을 설계했어요.

01Context

검증이 필요한 AI 분석 결과

사용자는 근로계약서와 현장 사진을 올리고, AI가 분석한 위험 요소를 확인해요. 연령과 디지털 숙련도가 다른 사용자가 이 결과를 보고 점검과 조치까지 이어가야 했어요.

인식 결과와 원문의 차이

OCR로 읽은 항목만 보여주면 잘못 인식된 부분을 찾기 어려워요.

다양한 문서와 화면

문서 형식⁠·⁠비율⁠·⁠화면 크기가 달라도 같은 방식으로 확인할 수 있어야 해요.

분석 이후의 행동

결과를 보여주는 데서 끝나면 무엇을 점검하고 조치할지 알기 어려워요.

설계 관점

자동 분석 결과보다, 사용자가 그 결과를 직접 검증하고 다음 조치를 알 수 있는지가 더 중요하다고 봤어요.

02User Flow

입력부터 조치까지 이어지는 점검 흐름

분석 결과 사이에 사용자가 직접 확인하는 단계를 남기고, KRDS 기준으로 익숙한 구조와 분명한 문장을 썼어요.

  1. 01

    자료 입력

    근로계약서와 현장 사진을 올려요.

  2. 02

    원문 확인

    OCR로 읽은 항목을 원문과 비교해요.

  3. 03

    결과 검토

    확인할 내용과 위험 요소를 읽어요.

  4. 04

    후속 조치

    자율점검과 조치 안내로 이어져요.

03Design Decisions

원문 비교와 파일별 확인 방식

사용자가 결과를 믿기 전에 직접 확인할 수 있도록, 원문과의 비교와 파일 조건별 동작을 먼저 정했어요.

01

원문을 검토의 기준으로

문제
인식 결과만 보여주면 잘못 읽힌 항목을 확인하기 어려워요.
판단
사용자가 결과를 직접 검증할 수 있어야 한다고 봤어요.
설계
원문과 OCR 결과를 함께 보여주고, 확인이 필요한 항목과 그 이유를 나눠 보여줬어요.

02

익숙한 공공 서비스 구조

문제
연령과 디지털 숙련도가 다른 사용자가 함께 이용해요.
판단
낯선 조작보다 익숙한 구조와 분명한 문장이 필요했어요.
설계
KRDS 기준을 바탕으로 입력 → 확인 → 조치의 흐름과 화면을 구성했어요.

03

파일 조건별 확인 방식

문제
긴 문서, 넓은 이미지, PDF, 확대 상태마다 내용을 확인하는 조건이 달랐어요.
판단
파일 특성이 달라도 내용을 놓치지 않도록 동작 기준을 먼저 정했어요.
설계
시안과 함께 파일 비율⁠·⁠형식⁠·⁠확대 상태별 동작 기준을 정해, 프론트엔드와 구현 결과를 맞췄어요.

파일 유형별 동작 기준

세로로 긴 문서

상하 스크롤을 중심으로 내용을 이어서 확인해요.

가로로 넓은 이미지

이미지가 잘리지 않도록 영역을 맞춰 전체 내용을 한눈에 봐요.

PDF 첨부 파일

문서 형식을 유지하면서 페이지 단위로 확인하는 뷰어로 보여줘요.

이미지 확대

세부 내용을 확대해 OCR 결과를 더 정확히 확인해요.

04AI Workflow

현장 위험을 설명하는 보조 이미지 제작

실제 사진이 부족한 위험 상황과 작업 환경은 생성 이미지로 보완해, 사용자가 상황을 쉽게 알아보게 했어요.

AI

AI에 맡긴 일

  • ChatGPT로 장면과 위험 요소를 구체화했어요.
  • Firefly와 나노바나나로 이미지를 생성했어요.

Designer

직접 판단한 일

  • 설명할 상황과 위험 요소를 정했어요.
  • 생성 결과를 검토하며 프롬프트를 다듬었어요.

05Key Screens

웹과 모바일의 점검 화면

웹은 메인 홈부터 시작 전 안내, OCR 결과 확인, 진단 결과, 위험 요소와 추천 교육 자료까지, 모바일은 파일 업로드부터 자율점검까지의 흐름이에요.

Web

Mobile

06Result

직접 확인하고 조치하는 점검 구조

분석 기능과 사용자의 확인 과정을 연결한 결과예요.

  1. 01

    원문 비교 검토 단계

    원문과 OCR 결과를 비교해 잘못 읽힌 항목을 사용자가 직접 확인해요.

  2. 02

    파일별 동작 기준

    세로⁠·⁠가로 이미지, PDF, 확대 상태까지 동작을 정리해 구현과 맞췄어요.

  3. 03

    이어지는 웹⁠·⁠모바일 흐름

    업로드부터 인식 결과 확인⁠·⁠분석⁠·⁠자율점검까지 이어져요.

이 프로젝트에서 보여준 역량

  • 검증할 수 있는 AI 결과자동 분석 결과를 사용자가 직접 확인하는 구조를 만들었어요.
  • 예외 상태 설계파일과 화면 조건이 달라도 작업이 이어지게 했어요.
  • 생성 결과의 판단설명 목적을 먼저 정하고 생성 이미지를 검토했어요.

다음 작업에 가져갈 기준

분석 기능을 제공하는 것과 사용자가 그 결과를 이해하고 확인하는 경험은 함께 설계해야 해요. AI가 만든 결과일수록 사용자가 확인하는 단계를 흐름 안에 남긴다는 기준이 생겼어요.
