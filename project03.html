흐름 중심 진단 구조 설계

사용자가 계약서, 사업장 사진을 업로드하거나 촬영하는 순간부터 AI 분석 결과 확인, 조치 안내까지 끊김 없이 이어지는 단계형 경험으로 구성

Why This Way? 정보 전달에 그치지 않고, 사용자가 실제 행동까지 이어질 수 있도록 다음 단계가 자연스럽게 연결되는 구조가 필요

대국민 접근성 기반 UI 설계 (KRDS 기반)

특정 사용자층이 아닌, 누구나 이해할 수 있도록 KRDS UI 기준을 기반으로 정보 구조와 인터페이스를 설계

Why This Way? 특정 사용자에 최적화된 UI는 범용성이 떨어지지만, KRDS 기반 구조는 별도 학습 없이도 누구나 이해 가능한 사용성을 확보할 수 있음
